# Safe House Insurance — safehouseins.com

A static site for a bilingual independent insurance agency licensed in Texas
and New Mexico. Every page is generated by a Python script in `tools/` and
committed as plain HTML. There is no build step at deploy time, no framework
and no node_modules: what is in the repo is what is served.

## The one rule that matters most

**Never hand-edit a generated `.html` file.** Find the generator that writes it
and change that. A hand edit survives until the next person runs the generator,
which is usually the same afternoon, and then it is gone with no trace of what
it was for.

Everything at the repo root except `404.html` is generated. So is everything
under `car-insurance/`, `learn/` and `docs/quote-preview.html`.

## Rebuilding

Run every generator, then the sitemap last. The sitemap walks what is on disk,
so it has to see the finished pages:

```
for g in genabout gencareers genlegal genmakes genguides genproduct gencities genpreview; do
  python3 tools/$g.py || break
done
python3 tools/gensitemap.py
```

**Run all of them, not just the one you think you touched.** The generators
share modules — `carriers.py`, `menu.py`, `nap.py`, `shell.py`, `brandkit.py`,
`citykit.py` — so a change to any of those lands in pages you did not have in
mind. Editing the carrier strip changes the five product pages, the car
insurance hub *and* all 21 guide pages, because guides carry the strip too.

## Where things live

| Module | Owns |
| --- | --- |
| `carriers.py` | The carrier list and the looping logo strip. `NAMES` is the only list. |
| `getlogos.py` | Fetches and imports carrier artwork. See `assets/carriers/README.md`. |
| `nap.py` | Business facts — name, address, phone, hours. One place, on purpose. |
| `menu.py` | The site menu panel, every page. |
| `guides_data.py` | Guide copy. Rendering is `genguides.py`. |
| `cities.py` / `places.py` | The city list and its per-city copy. |
| `makes.py` / `lineup.py` | Vehicle makes and their per-brand angle. |
| `states.py` | Statutory limits and state-level facts. |
| `shell.py`, `brandkit.py`, `citykit.py` | Shared page architecture. |

## Conventions that are not obvious

**Petal backgrounds go last in the stylesheet.** `.petal1` / `.petal2` paint a
radial gradient onto a section that also sets `background:` as a shorthand.
Anywhere but the end of the sheet, the shorthand resets them and they silently
do not paint.

**`carriers.py::NAMES` is the carrier list, but not the only place a carrier is
named.** A carrier we represent also appears in `genabout.py::CARRIERS` and in
the privacy policy in `genlegal.py`, in both languages. Removing one means all
three — the privacy policy names the companies we send an application to, so
listing a company we do not represent is a false statement about what happens
to a customer's data.

**Carrier artwork is never trusted without a person looking at it.** Validation
can check that a file decodes, is the right shape and is not a placeholder; it
cannot check that the logo belongs to the right company. Fetches have returned
The Wall Street Journal's logo for Root, American Family's for Connect, and an
unrelated insurer's for Commonwealth. Run `python3 tools/getlogos.py --sheet`
and look at `_review.html` before committing artwork.

**`lastmod` in the sitemap comes from `git log`, per file.** A shallow clone
makes `git log` return nothing, the generator falls back to file mtime, and a
fresh checkout stamps every page as modified today — which tells a crawler the
whole site changed when nothing did. CI must check out with full history
(`fetch-depth: 0`).

**Two carrier logo shapes, two file names.** `<slug>.svg` or `<slug>.webp` is
the wide wordmark for the strip; `<slug>-sq.webp` is the square badge for the
rate rows in `quote.html`. They are different files because the slots want
opposite shapes, and a wordmark squeezed into the square is unreadable.

## Checking your work

```
python3 tools/seocheck.py          # refuses things that were wrong before
python3 tools/dupcheck.py          # how alike the generated SEO pages are
python3 tools/getlogos.py --check  # which carriers have artwork
python3 tools/getlogos.py --selftest
python3 tools/smscheck.py          # SMS template length and cost
```

`seocheck.py` and `dupcheck.py` report known pre-existing findings — duplicate
titles are the `x.html` + `x/index.html` pairs serving one page two ways, and
city-page similarity is inherent to the format. Compare against the state
before your change rather than expecting silence.

## Browsers

Chromium and Playwright are preinstalled on the image, not in the project.
Playwright resolves through the global install:

```
NODE_PATH=/opt/node22/lib/node_modules node -e "const {chromium}=require('playwright'); ..."
```

Do not run `playwright install` and do not add Playwright to the project.

Verify visual changes at 1440, 960 and 390 px. The strip, the guide cards and
the city grids all change layout across those.

## Python

Standard library, plus Pillow and numpy where they are already used. No
requirements file and no virtualenv — anything new has to be worth the
dependency, and `tools/getlogos.py` was deliberately written to need only
Pillow so it runs anywhere.
